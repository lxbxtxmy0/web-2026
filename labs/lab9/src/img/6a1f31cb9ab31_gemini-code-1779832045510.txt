; Задача: поменять местами содержимое HL и DE без XCHG

PUSH H      ; Сохраняем HL в стек
PUSH D      ; Сохраняем DE в стек

POP H       ; Магия: верхнее значение из стека (бывшее DE) достаем в пару HL!
POP D       ; Следующее значение из стека (бывшее HL) достаем в пару DE!

; Результат: пары успешно поменялись значениями
